# Vendored browser scripts

* `elm-canvas.js`: the `elm-canvas` custom element used by the Elm `Canvas` package
  (joakin/elm-canvas 4.x). Version 2.2.4 of the npm package `elm-canvas`, MIT licence,
  unmodified (md5 `0e2b4768d759022746a64734af1b438d`). Served from this folder so the page
  does not depend on a CDN.

`elmulator.js` in this folder is generated by `npm run build:dev` or `npm run build:prod`.
